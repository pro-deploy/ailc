# Этап 2. Исследование ландшафта

**Роль:** модель с ailc

## Цель
Описать системы, интеграции, ограничения и риски, в которых будет жить решение.

## Входы
docs/brief.md, паспорт проекта .ailc/profile.md, существующий код (если есть).

## Шаги для модели
1. Скопируй .ailc/templates/landscape.md в docs/landscape.md.
2. Для существующего кода вызови run с id code.intel/map, code.intel/surface, затем code.intel/call_graph по затрагиваемым модулям и заполни раздел «Затрагиваемый код».
3. Посмотри паспорт проекта: персональные данные, русская локаль и обращения к нейросетям добавляют требования.
4. Каждый риск запиши с владельцем или пометкой «принят».

## Инструменты ailc
code.intel/map, code.intel/surface, code.intel/call_graph, code.intel/search, quality.check/layers, security.scan/deps.

## Запрещено на этом этапе
Писать код, менять бриф без согласия заказчика.

## Обязательный результат
docs/landscape.md с заполненными обязательными разделами.

## Условие перехода
Обязательные разделы карты заполнены. Затем stage advance.

## Сделай сейчас
Создай docs/landscape.md из шаблона и заполни раздел «Системы и интеграции» по брифу.
