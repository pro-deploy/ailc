# Этап 7. Проверка качества

**Роль:** модель с ailc

## Цель
Получить детерминированный вердикт гейта: тесты, секреты, уязвимости, линт, заморозка требований.

## Входы
Код после этапа 6.

## Шаги для модели
1. Вызови dod. Если есть блокеры, вызови stage action=return cycle=V с перечнем блокеров: процесс вернётся на этап 6, требования не меняются.
2. Если блокеров нет, вызови sarif для отчёта CI.

## Инструменты ailc
dod, sarif, plan (строгий режим), ailc fix.

## Запрещено на этом этапе
Ослаблять ailc.policy.toml, ставить ailc:ignore без объяснения причины, менять требования.

## Обязательный результат
Вердикт dod «подтверждено» и отчёт SARIF.

## Условие перехода
dod подтверждён. Затем stage advance (ailc сам перепроверит dod).

## Сделай сейчас
Вызови dod и разбери блокеры.
