# Этап 8. Развёртывание

**Роль:** команда

## Цель
Выкатить решение под новой версией, которой ещё не было.

## Входы
Код с подтверждённым dod, история тегов git.

## Шаги для модели
1. Узнай текущую версию на проде и последний git-тег.
2. Подними версию по семантическому версионированию: слом API (verify/api-break) даёт мажорную, новая функция минорную, исправление патч.
3. Вызови run с id generate/release-notes.
4. Создай git-тег vX.Y.Z на коммите выкатки и вызови stage action=advance с version=vX.Y.Z.

## Инструменты ailc
generate/release-notes, deliver/change-log, verify/api-break, generate/sbom.

## Запрещено на этом этапе
Перезаписывать уже выпущенный тег, выкатывать без dod, менять требования.

## Обязательный результат
Развёрнутая версия vX.Y.Z и git-тег.

## Условие перехода
Передан version, такого тега не было в истории процесса, git-тег существует. Затем stage advance.

## Сделай сейчас
Определи текущую версию и предложи следующую.
