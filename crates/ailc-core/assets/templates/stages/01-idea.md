# Этап 1. Идея заказчика

**Роль:** заказчик отвечает, модель спрашивает и записывает

## Цель
Понять, какую проблему решаем, для кого и что будет считаться успехом.

## Входы
Сообщения заказчика в чате.

## Шаги для модели
1. Скопируй шаблон .ailc/templates/brief.md в docs/brief.md, если файла ещё нет.
2. Вызови инструмент ailc run с id spec/questions и задай заказчику вопросы по незаполненным разделам брифа. К каждому вопросу предлагай черновик ответа.
3. Ответы записывай в docs/brief.md и через spec/answer.
4. Задавай не больше трёх вопросов за раз.

## Инструменты ailc
spec/questions, spec/answer, memory/update.

## Запрещено на этом этапе
Писать код, выбирать технологии, создавать ADR.

## Обязательный результат
docs/brief.md с заполненными разделами «Проблема», «Для кого», «Цель и метрика успеха», «Что входит в объём».

## Условие перехода
Все обязательные разделы брифа заполнены. Затем вызови stage с action=advance.

## Сделай сейчас
Открой docs/brief.md (или создай из шаблона) и задай заказчику вопрос по первому пустому обязательному разделу.
