# Обзор проекта

_Раздел между метками обновляется сам при каждом запуске. Всё, что вы допишете снаружи меток, сохранится._

В проекте 2607 значимых определений — функций, типов и тому подобного — собранных в 13 частей. Использованные языки: javascript, python, rust.

## Из чего он складывается

**crates/ailc-capabilities/src** — 1004 определения, из них доступны другим частям 180. Среди них: fn register, fn new, type LlmTaintCapability, fn insecure_output_scan, fn prompt_injection_scan.

**crates/ailc-capabilities/tests** — 95 определений.

**crates/ailc-contracts/src** — 57 определений, из них доступны другим частям 38. Среди них: type GateReport, type PolicyPack, type Thresholds, type GatePolicy, type RunInput.

**crates/ailc-core** — 1 определение.

**crates/ailc-core/src** — 492 определения, из них доступны другим частям 133. Среди них: fn run, type AgentOrchestrator, fn today, fn set, fn get.

**crates/ailc-core/src/engines** — 706 определений, из них доступны другим частям 124. Среди них: fn extract, type ApiDoc, type ApiItem, fn extract, fn is_empty.

**crates/ailc-core/src/standards** — 29 определений, из них доступны другим частям 20. Среди них: fn draft_text, fn completeness, fn is_required, fn complete, fn percent.

**crates/ailc-core/tests** — 59 определений.

**crates/ailc-testkit/src** — 10 определений, из них доступны другим частям 5. Среди них: fn ctx, fn write, fn path, fn new, type TempTree.

**crates/ailc/examples** — 16 определений.

**crates/ailc/src** — 123 определения, из них доступны другим частям 9. Среди них: fn run, fn uninstall, fn install, fn run, fn run_once.

**npm/ailc-mcp/bin** — 8 определений.

**tools** — 7 определений, из них доступны другим частям 7. Среди них: fn main, fn compact, fn preferred_id, fn ranges_of, fn severity_of.

## Как части связаны между собой

Замкнутых в круг зависимостей между частями не обнаружено — это хороший признак: части можно менять по отдельности.
