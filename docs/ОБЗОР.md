# Обзор проекта

_Раздел между метками обновляется сам при каждом запуске. Всё, что вы допишете снаружи меток, сохранится._

В проекте 1808 значимых определений — функций, типов и тому подобного — собранных в 9 частей. Использованные языки: javascript, rust.

## Из чего он складывается

**crates/ailc-capabilities/src** — 821 определение, из них доступны другим частям 148. Среди них: fn register, fn new, type TaintScan, fn new, type SastScan.

**crates/ailc-capabilities/tests** — 60 определений.

**crates/ailc-contracts/src** — 56 определений, из них доступны другим частям 37. Среди них: type GateReport, type PolicyPack, type Thresholds, type GatePolicy, type RunInput.

**crates/ailc-core/src** — 258 определений, из них доступны другим частям 60. Среди них: fn weakness_warning, fn load, fn to_sarif, fn get_arc, fn get.

**crates/ailc-core/src/engines** — 470 определений, из них доступны другим частям 91. Среди них: fn call_graph, fn reachability_confidence, fn unreachable, type CallGraph, type ReferenceHits.

**crates/ailc-core/tests** — 60 определений.

**crates/ailc/examples** — 16 определений.

**crates/ailc/src** — 62 определения, из них доступны другим частям 9. Среди них: fn uninstall, fn install, fn run, fn run_once, fn run.

**npm/ailc-mcp/bin** — 5 определений.

## Как части связаны между собой

Замкнутых в круг зависимостей между частями не обнаружено — это хороший признак: части можно менять по отдельности.
