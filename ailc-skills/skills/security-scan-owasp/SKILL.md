# security.scan/owasp

Обзор по OWASP Top 10 (A01–A10) с матрицей покрытия, file:line и рекомендациями. Покрытие паттерновое: пустая категория означает «по ограниченному набору паттернов», а не доказанное отсутствие уязвимостей; ручной обзор остаётся желательным.

## Как запустить

Через MCP-сервер ailc (один офлайновый бинарь, без внешних сервисов):

- `run { "id": "security.scan/owasp", "path": "<путь к проекту>" }`
- семантический подбор под намерение: `find_capability { "query": "..." }`

Через CLI:

```
ailc cap security.scan/owasp <путь>
```

Находки возвращаются структурно (file:line + severity) и проходят состязательную верификацию — в балл и гейт идут только подтверждённые. Семейство `security`, движок `scan`, тир `core`.
