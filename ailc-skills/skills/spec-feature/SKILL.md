# spec/feature

Спроектировать новую фичу: заготовка спеки (зачем/что/критерии приёмки/затрагиваемые части) + ADR-решение. Описание фичи — в query.

## Как запустить

Через MCP-сервер ailc (один офлайновый бинарь, без внешних сервисов):

- `run { "id": "spec/feature", "path": "<путь к проекту>" }`
- семантический подбор под намерение: `find_capability { "query": "..." }`

Через CLI:

```
ailc cap spec/feature <путь>
```

Находки возвращаются структурно (file:line + severity) и проходят состязательную верификацию — в балл и гейт идут только подтверждённые. Семейство `spec`, движок `generator`, тир `core`.
