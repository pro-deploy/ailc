# security.scan/terraform

Опасные настройки инфраструктуры как кода на языке HCL (Terraform и OpenTofu): группа безопасности с входящим правилом от 0.0.0.0/0 или ::/0, объектное хранилище с публичным доступом, том или база данных с явно отключённым шифрованием, учётные данные строковым литералом в описании поставщика или ресурса, отключённое версионирование хранилища, отключённое ведение журнала доступа и аудита, хранение состояния без шифрования, политика доступа с подстановочным знаком одновременно в действиях и в ресурсах. Применять к каталогам с файлами tf, tfvars и hcl до выполнения команды apply.

## Как запустить

Через MCP-сервер ailc (один офлайновый бинарь, без внешних сервисов):

- `run { "id": "security.scan/terraform", "path": "<путь к проекту>" }`
- семантический подбор под намерение: `find_capability { "query": "..." }`

Через CLI:

```
ailc cap security.scan/terraform <путь>
```

Находки возвращаются структурно (file:line + severity) и проходят состязательную верификацию — в балл и гейт идут только подтверждённые. Семейство `security`, движок `scan`, тир `core`.
