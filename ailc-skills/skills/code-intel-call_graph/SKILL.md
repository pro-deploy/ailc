# code.intel/call_graph

Граф вызовов: кто какую функцию зовёт. Показывает радиус влияния изменения и потенциально недостижимые функции. Точный AST-разбор; вызовы во вне (библиотеки/динамика) помечаются явно.

## Как запустить

Через MCP-сервер ailc (один офлайновый бинарь, без внешних сервисов):

- `run { "id": "code.intel/call_graph", "path": "<путь к проекту>" }`
- семантический подбор под намерение: `find_capability { "query": "..." }`

Через CLI:

```
ailc cap code.intel/call_graph <путь>
```

Находки возвращаются структурно (file:line + severity) и проходят состязательную верификацию — в балл и гейт идут только подтверждённые. Семейство `code.intel`, движок `codeintel`, тир `core`.
