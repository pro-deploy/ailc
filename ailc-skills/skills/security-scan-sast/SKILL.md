# security.scan/sast

Глубокий структурный анализ безопасности (AST): инъекции кода/команд, SQL через конкатенацию, небезопасная десериализация. Точнее regex (смотрит структуру вызова, не текст). Тяжёлый — для полного пентеста, не для обычной проверки.

## Как запустить

Через MCP-сервер ailc (один офлайновый бинарь, без внешних сервисов):

- `run { "id": "security.scan/sast", "path": "<путь к проекту>" }`
- семантический подбор под намерение: `find_capability { "query": "..." }`

Через CLI:

```
ailc cap security.scan/sast <путь>
```

Находки возвращаются структурно (file:line + severity) и проходят состязательную верификацию — в балл и гейт идут только подтверждённые. Семейство `security`, движок `codeintel`, тир `enterprise`.
